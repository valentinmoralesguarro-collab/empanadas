# Empanadas Convi

App para organizar la venta de empanadas de la comunidad: gastos, tandas, quién se llevó cuántas, cuánta plata entró y a quién hay que devolverle.

- Probar ya (modo prueba, datos solo en tu dispositivo): `python3 -m http.server 8810` y abrir http://localhost:8810/
- Publicarla para todos: `../empanadas-backend/CONFIGURAR.md`.
- Estado y decisiones: `PROGRESS.md`.
